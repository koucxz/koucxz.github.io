# 寇晨迪 · AI 应用工程师线上简历

面向 AI 应用工程师岗位的线上简历与项目作品集，采用专业的中浅蓝视觉。首页包含个人技术栈、个人项目、技术能力和工作经历；个人项目均配置真实演示动图。

## 本地运行

```bash
npm install
npm run dev
```

## 页面

- `/`：线上简历主页
- `/resume`：两页线上简历预览页，可直接下载矢量文字 PDF

## 部署

项目为 Vite 静态站点，当前部署在 GitHub Pages 用户站点：

```bash
npm run build
```

构建产物会自动生成 `dist/resume/index.html`，无需手工复制路由入口。
